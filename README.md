# Glimpse

Glimpse is a browser-based QR code studio for creating, customizing, and exporting QR codes. It includes a public landing page and a focused workspace for designing codes and managing projects. QR encoding, previews, and image exports run in the browser; the app does not require an application server or account.

## Deployment

[Open Glimpse](https://glimpse01.vercer.app)

The production site is hosted on Vercel. The Vercel configuration builds the Vite app into `dist/` and rewrites incoming paths to `index.html`, allowing client-side routes, including the not-found page, to load on direct visits and refreshes.

## Features

### Create QR codes

Choose from five content types:

- **URL**: web addresses, with `https://` added when no scheme is entered.
- **Plain text**: text up to 1,500 characters.
- **Email**: recipient, optional subject, and optional message, encoded as a `mailto:` payload.
- **Phone**: phone numbers encoded as a `tel:` payload.
- **Wi-Fi**: network name, WPA/WEP/open security, password, and hidden-network setting.

Input is validated before it is encoded. A project name is for library and download organization only; it is not included in the QR payload.

### Customize and preview

- Set foreground and background colors, or use a linear or radial gradient.
- Choose square, rounded, or dot modules.
- Set the quiet-zone margin from 0 to 10 modules.
- Select QR error correction level L, M, Q, or H.
- Add an image logo in the center and adjust its size. Large images are scaled down during preparation, and the workspace warns about scan-risk settings such as low contrast, narrow margins, or an oversized logo.
- Choose an export size from 256 to 2,048 pixels.
- Start from one of eight visual templates. Templates change appearance without replacing QR content, output size, logo, or error correction.
- Undo and redo edits, with up to 100 history steps.

### Export and manage projects

- Export as PNG or SVG. The preferred download format can be selected in Settings.
- Share the generated PNG where the browser supports file sharing; otherwise, use the available copy or download fallback.
- Save named projects to Recents, pin projects in Favorites, and revisit generated files in Downloads.
- Resume the single automatically saved draft or start a new project.
- Choose light, dark, or system theme, and clear individual libraries or all app data from Settings.

## QR generation and data

The QR encoder in `src/lib/qr/encoder.js` supports byte-mode QR codes across versions 1-40 and all four standard error-correction levels. QR matrix layout, preview rendering, SVG generation, and PNG rendering are handled by the QR service.

Glimpse stores project records, drafts, favorites, recents, and downloaded image blobs in the browser's IndexedDB. Theme and download-format preferences and the automatic-name counter use local storage. QR payloads and uploaded logos are processed locally; they are not sent to a Glimpse backend. Data is specific to the current browser profile and device, and clearing browser site data removes it. Use **Settings > Clear all local data** to erase Glimpse's stored data from within the app.

The browser's native share and clipboard APIs are optional; their availability depends on the browser and platform. Other core features require a modern browser with IndexedDB, Canvas, SVG, and TextEncoder support.

## Tech stack

- React 18 and React Router for the interface and client-side routes.
- Vite for local development and production builds.
- Tailwind CSS for styling.
- Framer Motion for interface animation.
- Lucide React for icons.
- A project-local QR encoder; QR codes are not generated by a remote API.

## Project structure

```text
public/                   Static assets, including the favicon and landing-page image
src/
  components/
    app/                  QR workspace, editor controls, dialogs, and library views
    app/customizer/       Appearance, size, quality, and logo controls
    brand/                Glimpse brand mark
    fx/                   Reusable visual effects and motion components
    landing/              Landing-page sections
    qr/                   QR artwork rendering
  hooks/                  Project state, drafts, library, and media helpers
  lib/
    qr/                   QR encoder implementation
    PageNotFound.jsx      Client-side not-found page
    sections.js           Workspace navigation sections
    templates.js          Visual presets
  pages/                  Landing and generator route components
  services/               QR rendering/export and browser-storage services
  utils/                  Content validation and naming helpers
```

`src/App.jsx` defines the `/` landing route, `/app` workspace route, and wildcard not-found route. `src/main.jsx` mounts the application, while `src/index.css` and `tailwind.config.js` define the styling system.

## Requirements

- Node.js 20.19+ or 22.12+.
- npm.
- A modern browser for using the app.

## Run locally

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. The workspace is available at `/app`; an unknown path displays the Glimpse not-found page.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server. |
| `npm run lint` | Run ESLint. |
| `npm run lint:fix` | Run ESLint and apply supported automatic fixes. |
| `npm run typecheck` | Run the TypeScript checker using `jsconfig.json`. |
| `npm run build` | Build the production site into `dist/`. |
| `npm run preview` | Serve the production build locally. Run `npm run build` first. |

There is no automated test script configured in `package.json` at this time.

## Build and deploy

Create and preview a production build locally:

```sh
npm run build
npm run preview
```

The included `vercel.json` configures Vercel to run `npm run build`, publish `dist/`, and rewrite requests to the SPA entry point so client-side routes work on direct navigation. Deploy the repository to Vercel and let it use the included configuration, or set the framework to Vite, the build command to `npm run build`, and the output directory to `dist/`.

**Deployment URL:** [https://glimpse01.vercer.app](https://glimpse01.vercer.app)
